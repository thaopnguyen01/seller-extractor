🗂️ How It Connects to Your Team's Google Sheets Workspaces

This extension doesn't just extract data — a companion Google Apps Script, installed once per spreadsheet, turns a pasted JSON blob into a fully-filled row in your team's actual tracking workspace, matching each workspace's own column layout exactly.

Workspace What Gets Auto-Filled Formula-Protected Columns
Amazon / Walmart Product URL, Seller Name/URL, Title —
Alibaba Raw Listing URL, Seller URL (with trailing slash), Title, Date Found Listing ID, Listing URL
AliExpress US Seller URL, Raw Listing/Seller URL, Title, Date Found Listing ID, Listing URL
AliExpress EU (ES/FR/DE) Seller URL, Raw Listing/Seller URL, Title, Date Found Listing ID, Listing URL
TikTok Raw Content Link, User ID, Associated URL, Email/Phone/Telegram/Snapchat/Instagram/Other, Title ID Number, Content Link, Handle
LinkedIn Merchant Name, Page, Associated Domain, Title, Text, Content ID/URL, Target URL, Updated At —
Why some columns are skipped on purpose: several workspaces already use live ARRAYFORMULAs to derive things like the Listing ID or a cleaned URL directly from a raw link column. The script knows exactly which columns those are per workspace and never writes to them — so pasting new data can never silently break an existing formula.
Setup: the script is bound to a specific Google Sheet file, not an individual tab — so it only needs to be pasted once per spreadsheet (Extensions → Apps Script) to work across every tab inside it. Each contract workspace (Alibaba, AliExpress US, AliExpress EU, TikTok, LinkedIn, Amazon/Walmart) keeps its own copy, since each has a different column layout.

📦 Installation (5 Minutes)

  1. Download the extension

    Click the download button above to get the latest version

  2. Extract the ZIP file

    Unzip the downloaded file to any folder on your computer

  3. Open Chrome Extensions

    Go to chrome://extensions/ in your browser address bar

  4. Enable Developer Mode

    Toggle the "Developer mode" switch in the top-right corner

  5. Load the extension

    Click "Load unpacked" and select the extracted seller-extractor folder

That's it! The extension is now installed and ready to use. For Sheets auto-fill, ask your team lead for the Apps Script matching your workspace.
